How This Progression Works

Owning the complete Marvel Champions LCG collection creates a strange problem: almost everything is available at once. This guide deliberately removes that choice overload. Instead of treating the collection as one enormous card pool, you recreate the history of the game, one release at a time — learning what each hero was designed to do, rebuilding it with the historical card pool, and gradually completing the full Hero x Scenario matrix.

The Standard Hero Procedure

  1. Play the hero's untouched precon vs Standard Klaw — the learning game.
  2. Play the exact same precon vs Expert Klaw + Masters of Evil — the historical benchmark. Don't improve the deck first.
  3. Evaluate the precon: dead cards, resource problems, setup speed, threat control, damage, survivability.
  4. Modify or rebuild the deck, using only player cards released by that point in the chronology.
  5. Take the modified deck back against the exact same Expert Klaw + Masters of Evil configuration.
  6. Record the result, then begin using the hero against your unlocked scenario library.

Why Expert Klaw?

Klaw asks a deck to do several things rather than test one extreme: threat pressure, side schemes, minions, encounter-card pressure, an awkward opening board. Keeping one Klaw configuration unchanged gives the whole project a consistent measuring stick — a hero released years later is asked to pass the same exam as an early Core Set hero. Losing isn't a failure; the interesting comparison is Precon Expert Klaw vs. Custom Expert Klaw.

The Matrix Rule That Prevents Burnout

The full Hero x Scenario matrix is the ultimate completionist objective, not a gate that blocks new content. When a new hero appears, benchmark it and use it against current content. When a new scenario appears, play it and add it to the library. Older combinations can be filled in whenever you want to revisit them — this keeps the collection moving forward while the matrix slowly fills in behind you.

Difficulty Levels

The Log tab supports every encounter-set difficulty currently in print: Standard I, Standard II (The Hood), Standard III (Age of Apocalypse), Expert I, Expert II (The Hood), and Heroic (a chosen numeric level stacked on top, with no fixed cap). Expert III has not been released by Fantasy Flight Games as of this writing, so it isn't listed — it can be added easily once it exists. Only exact Standard I and Expert I plays against Klaw count toward the official hero benchmark steps, matching the Standard Hero Procedure above. Klaw benchmark steps are derived from your logged plays — Standard and Expert are tracked as fully separate steps, so an Expert win no longer auto-completes the Standard step.

Suggested Klaw Benchmark Notes

For each hero, capture: precon result & attempts, custom result & attempts, aspect used, setup speed, threat control, minion handling, resource economy, survivability, key overperforming cards, dead precon cards, and the single biggest change that improved the custom deck. Use the Notes field on each hero card in the Phases tab.

A Good Session Structure

One benchmark game plus one progression game is enough for a normal evening — e.g. a newly unlocked hero's precon vs Expert Klaw, a few minutes of deck tweaking, then the custom version against the newest campaign scenario. Return to Expert Klaw for the custom benchmark another night. This keeps the lab from feeling repetitive.

Final Principle

The roadmap exists to make a huge collection feel smaller. Never let completionism reverse that purpose. The chronological unlock order gives every product a moment to breathe; the fixed Klaw benchmark gives every hero a common test; and the matrix gives you a permanent long-term objective. You are allowed to progress before the matrix is complete. The matrix is the journey after the journey.
